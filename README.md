## 📌 Project Overview

This project is a **Global Airbnb Performance Dashboard built using Power BI**, designed to analyze Airbnb’s business performance across major global cities.  

The dashboard focuses on transforming raw listing data into **meaningful business insights** related to market presence, pricing behavior, customer satisfaction, and platform growth trends.

The final output is an **interactive business intelligence dashboard** that supports strategic decision-making.

## 🔄 Project Workflow

1. **Data Collection & Understanding**  
   Explored Airbnb dataset structure and identified key business metrics.

2. **Data Cleaning (Power Query)**  
   - Handled missing values  
   - Standardized data formats  
   - Removed inconsistencies  
   - Transformed raw data into analysis-ready format  

3. **Data Modeling**  
   Built relationships between tables to ensure efficient reporting and accurate insights.

4. **Dashboard Development**  
   Designed interactive visuals including:
   - Trend analysis charts  
   - Market share distribution  
   - Pricing comparison visuals  
   - Customer satisfaction heatmaps  
   - Seasonal behavior patterns  

5. **Insight Generation**  
   Converted visual patterns into **business-ready insights for decision-making**.
